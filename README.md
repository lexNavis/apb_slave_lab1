# apb_slave_lab1
## Кратко о репозитории
Данный репозиторий содержит исходный код apb слейва 
и тестбенча, играющего роль мастера.
## Описание программ
Слейв поддерживает обмен и выдавать сообщения о совершаемых операциях. 
При записи 0 в младшем бите регистра со смещением 0 должно сохраняться и оставаться значение hAAAA_AAAA, а при записи 1 - значение h5555_5555.
Распределение регистров по адресам:
* 0x0 - регистр номера группы
* 0x4 - регистр даты
* 0x8 - регистр фамилии
* 0xC - регистр имени

Тестовый модуль проверяет чтение и запись в указанные регистры с выводом сигналов и результатом совершаемых операций

## Запуск
Запуск проводить в любом симуляторе.
### Через .do файл
```modelSim
do run.do
```
### Списком команд
```modelSim
vlib work
vlog -sv apb_slave.sv tb_apb_slave.sv
vsim TB
run -all
```
