# APB Slave: вывод π и e

APB slave, возвращающий π и e в формате IEEE 754 double (64 бита) через два 32-битных регистра.

**Авторы:** Шеин Денис, Аборин Артём
**Группа:** М3О-409Б-23

## Регистры

| Адрес | Регистр | Описание |
|-------|---------|----------|
| 0x0 | `ctrl_reg` | бит 0: 0 = π, 1 = e; бит 1: 0 = lo, 1 = hi |
| 0x0 (чтение) | `prdata` | `pi_lo` / `pi_hi` / `e_lo` / `e_hi` по `ctrl_reg` |

## Константы (IEEE 754 double)

| Число | hi | lo |
|---|--------------|--------------|
| π | `0x400921FB` | `0x54442D18` |
| e | `0x4005BF0A` | `0x8B145769` |

## Запуск
